# A入力資料の配置方法

A実行前に、次の3ファイルを**このフォルダにコピー**する。原本を移動・削除しない。

1. `constraints.md` ← `docs/product/constraints.md`
2. `feature-inventory.md` ← `docs/product/feature-inventory.md`（**全機能の確認・追記後**）
3. `developer-observation.md` ← ユーザー自身のQ1〜Q6の自己観察。機密情報を除去する。

入力はすべてGitで追跡して構わない公開可能なものだけにする。未公開作品や個人情報、実際の原稿は入れない。
入力の変更後は実行前に再確認する。Aのエージェントは`inputs/`を編集しない。
