# シナリオB：小説作者の困りごとから考える調査

## 何をするの？
自分たちが考えた機能に引っ張られず、小説を書く人が設定を探す・保存する・直すときの問題を調べます。

## 誰のため？
小説家になろう、カクヨム、アルファポリスなどで書く作者を想定します。PCを使う人が対象ですが、スマホで書く人がPCで設定を管理する可能性も調べます。

## 何を見ればいい？
- 調査する質問: `questions.md`
- 実行ルール: `AGENTS.md`
- 設定: `config.yaml`
- 調査結果: `outputs/01-research/`
- 専門的な分析: `outputs/03-analysis/`
- **一番最初に読む結果**: `outputs/06-final-report/README.md`

## やらないこと
既存の機能一覧を見ない。A/Cを実行しない。小説本文を書く機能を考えない。新しい機能を勝手に確定しない。

## 調査が終わったら
開発者が報告を読み、追加調査・採用候補・保留を判断します。調査終了は「機能の採用が決まった」ことを意味しません。
