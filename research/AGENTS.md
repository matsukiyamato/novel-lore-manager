# 調査全体の共通ルール

- `research/common/research-policy.md` と `research/common/evidence-policy.md` を参照する。
- 事実 / 当事者の体験 / 競合の仕様 / AIの解釈 / 未確認事項を別々に書く。
- 個人ブログ、SNS、レビューは、原則として投稿者個人の経験の根拠とし、市場全体への一般化を禁止する。
- 元資料からの要約・解釈には識別子を付ける。引用は必要最小限とし、長文の転載は禁止転載をしない。
- 各調査の入力と出力を記録。少数意見・反証・重大リスクを削除しない。
- A/Bの相互汚染を避ける。Aの作業でB/Cの入力・出力を読んだり変更したりしない。
- 最終承認は開発者。エージェントが決定ログに採用確定を記入しない。
