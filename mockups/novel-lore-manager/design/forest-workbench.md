# Forest Workbench — 視覚仕様

状態：3テーマ比較用の設計提案。構造・文言・操作は `shared-ux.md` と `shared-wireframes.md` に従う。製品仕様の承認ではない。

## 計画→批評→改訂

初案：深緑の作業面、木の机、鈍い金属の枠。日本語ゴシックを主に、SCR-02とSCR-06の選択資料を「見出し札」として示す。長文は左揃え。

```text
共通上端
機能ナビ | 資料探索 | タブ[見出し札] / 無地の編集面 | 関連資料
共通下端              Quick Recall: 検索 / 結果[見出し札] / 概要
```

批評：木目、金線、発光を重ねればゲーム風の汎用暗色エディタになる。木は探索面の温度差、金属は意味を持つ鈍い境界に限定。金は焦点と検索一致だけ。見出し札は既存の選択線と資料名で表し、DOMや情報を足さない。

## 基本色：6色

| 名称 | HEX | 用途 |
|---|---|---|
| 林床 `canvas` | `#151F1B` | 外周・機能ナビ |
| 深緑の作業面 `surface` | `#1D2A24` | 編集・プレビュー・概要 |
| 杉影 `surface-raised` | `#25352C` | タブ・入力・選択 |

| 若葉 `accent` | `#C4D7A4` | 選択・リンク・主要操作 |

意味色の補助値：焦点・検索一致 `#F2D17F`、意味のある境界 `#6D8373`、失敗・削除警告 `#F0A9A1`。木目や金属柄の画像は使わない。

単色対比の計算値：本文／作業面13.12:1、補助／作業面8.24:1、本文／杉影11.38:1、若葉／作業面9.66:1、焦点／作業面10.08:1、境界／作業面3.65:1・杉影3.17:1、警告／作業面7.73:1。SCR-02本文・選択タブ・DIRECT注意、SCR-06検索欄・結果・概要、モーダル、無効表示で、実装後に合成色と描画後の対比を再確認する。通常文字4.5:1、意味を持つ境界・アイコン・焦点3:1を下限とする。

## 文字・造形

- 日本語UIとプレビュー：`Yu Gothic UI`, `Meiryo`, `Noto Sans CJK JP`, sans-serif。操作14px/500、本文16px/400、画面見出し20px/600、文書見出し24/20/18px。プレビュー本文行高1.7。
- Markdownソース：`Cascadia Code`, `Consolas`, `Yu Gothic UI`, `Meiryo`, monospace。16px/1.65。ラテン記号の整列と日本語のオフライン字形を両立する。
- 全テーマ共通の4px刻み：行内8px、操作間8px、領域内16px、見出し下24px。長文約60〜75字、左揃え。両端揃え・中央揃えは使わない。行高、タブ高、パネル幅をテーマで変えない。
- 通常境界1px、選択は領域内2px線、角丸4px。影はモーダルと独立小窓の外縁だけ。本文にテクスチャなし。

## 状態と記憶点

| 状態 | 表現 |
|---|---|
| 選択 | 杉影の面＋若葉の2px内側線＋文字ウェイト。タブには共通の下線も残す |
| hover / pressed | 面の明度差と内側輪郭。寸法は固定 |
| focus | 金の2px外側輪郭。選択と同時に見える |
| disabled | 制御を低彩度化し、必要な理由は通常の文字対比で表示。操作不能もセマンティクスで示す |
| unsaved / saved / error | 同じ位置に「未保存」「保存済み」「保存に失敗」。失敗には対象・理由・再試行 |
| archived / trashed | 状態語「アーカイブ済み」「削除済み」とアイコン。薄い文字だけで表さない |

記憶点は**資料見出し札**一つ。SCR-02の選択タブ、SCR-06の選択結果行に同じ短い内側線と資料名を使い、所在を追いやすくする。演出は探索・選択に限定。Markdown入力、プレビュー本文、検索抜粋、ウィザードの影響説明、エラー、削除確認は無地で実務的にする。保存・Undo・表示切替・DIRECTの位置と文言は共通。

同型カード、広告的ヒーロー、根拠のないグラフ、無意味な見出し、全大文字ラベル、葉の透かし、ネオン、装飾アニメーションは禁止。操作結果以外の動きを置かず、`prefers-reduced-motion`で遷移をなくす。1366×768・1440×900・1920×1080、125%・150%相当、キーボードと失敗・空状態は実装後に検証する。現段階では未実測。
