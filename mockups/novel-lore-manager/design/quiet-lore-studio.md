# Quiet Lore Studio — 視覚仕様

状態：3テーマ比較用の設計提案。構造・文言・操作は `shared-ux.md` と `shared-wireframes.md` に従う。製品仕様の承認ではない。

## 計画→批評→改訂

初案：自然光の入る現代の書斎。セージ、明るい無地の作業面、ゴシック体、少ない影。現在資料と検索入力を先に見せる。

```text
共通上端
機能ナビ | 資料探索 | タブ[現在位置の帯] / 連続した編集面 | 関連資料
共通下端              Quick Recall: 検索 / 結果[現在位置の帯] / 概要
```

批評：淡色と大きな余白だけでは汎用SaaS画面になり、選択も曖昧になる。余白や行高は増やさず、現在資料の端だけにセージの帯を置く。自然光はグラデーションでなく明るい面と濃い文字で表す。焦点は選択と別の青にする。

## 基本色：6色

| 名称 | HEX | 用途 |
|---|---|---|
| 朝の壁 `canvas` | `#F2F5F0` | 外周・機能ナビ |
| 光の作業面 `surface` | `#FFFEFA` | 編集・プレビュー・概要 |
| セージ面 `surface-raised` | `#E6EEE7` | タブ・入力・選択 |
| 深緑墨 `text` | `#23342B` | 本文・見出し |
| 石緑 `text-muted` | `#526158` | 補助説明 |
| 深いセージ `accent` | `#315F4A` | 選択・リンク・主要操作 |

意味色の補助値：焦点 `#245EAA`、意味のある境界 `#82988A`、失敗・削除警告 `#9B3333`。自然光を理由に意味色を薄くしない。

単色対比の計算値：本文／作業面13.03:1、補助／作業面6.48:1、本文／セージ面11.11:1、深いセージ／作業面7.26:1、焦点／作業面6.39:1、境界／作業面3.06:1、警告／作業面7.14:1。SCR-02本文・選択タブ・関連情報、SCR-06検索欄・結果・概要、DIRECT注意、モーダル、無効表示を検証対象とする。境界／セージ面や合成色は実装後に測る。通常文字4.5:1、意味を持つ境界・アイコン・焦点3:1を下限とする。

## 文字・造形

- 日本語UI・プレビュー：`Yu Gothic UI`, `Meiryo`, `Noto Sans CJK JP`, sans-serif。操作14px/500、本文16px/400、画面見出し20px/600、文書見出し24/20/18px。プレビュー本文16px/1.7。
- Markdownソース：`Cascadia Code`, `Consolas`, `Yu Gothic UI`, `Meiryo`, monospace。16px/1.65。日本語のオフライン字形を確保する。
- 全テーマ共通の4px刻み：行内8px、操作間8px、領域内16px、見出し下24px。長文約60〜75字、左揃え。両端揃え・中央揃えの長文なし。静けさを余白量の増加で作らない。
- 通常境界1px、選択は領域内2px線、角丸4px。影はモーダルと独立小窓の外縁だけ。グラデーション・ぼかし・ガラス効果なし。

## 状態と記憶点

| 状態 | 表現 |
|---|---|
| 選択 | セージ面＋深いセージの2px内側線＋文字ウェイト。タブには共通の下線 |
| hover / pressed | 面と境界を一段変える。寸法は固定 |
| focus | 青の2px外側輪郭。選択の緑と同時に認識できる |
| disabled | 操作不可の外観とセマンティクス。理由は通常の文字対比 |
| unsaved / saved / error | 同位置の「未保存」「保存済み」「保存に失敗」。失敗には対象・理由・再試行 |
| archived / trashed | 状態語とアイコン。グレーアウトだけに頼らない |

記憶点は**現在位置の細い帯**一つ。SCR-02の選択タブ・探索行、SCR-06の選択結果行の端に同じ2pxのセージ帯を内側に描く。帯は選択という意味を持ち、新しい装飾領域を足さない。演出は現在位置と検索入力の境界まで。Markdown入力、検索抜粋、COPY/DIRECT説明、エラー、削除確認は無地。Quick Recallの検索→結果→概要の順序は共通。

同型カード、広告的ヒーロー、根拠のないグラフ、無意味な見出し、全大文字ラベル、植物イラスト、巨大な角丸、装飾アニメーションは禁止。操作結果以外の動きを置かず、`prefers-reduced-motion`で遷移をなくす。1366×768・1440×900・1920×1080、125%・150%相当、キーボードと失敗・空状態は実装後に検証する。現段階では未実測。
