# 共通低忠実度ワイヤーフレーム

状態：2026-11-02の設計提案。寸法、キー操作、配置はモック比較用の暫定案。3テーマは同じ構造・データ・文言・遷移を使用する。`docs/screen-specifications.md` SCR-01〜08／MOD-01〜04に対応。

## SCR-02：資料を開いた通常状態（1366×768の想定）

```text
┌──────────────────────────────────────────────────────────────────────────────────────────────┐
│ [作品選択へ] 作品：霧の王都       [Quick Recall] [テーマ]                                 │
├────────┬──────────────────────┬─────────────────────────────────────────┬────────────────────┤
│資料    │ 資料を探す           │ [王都の地理 ●][登場人物]  [+]         │ 関連資料 [閉じる]  │
│検索    │ [フォルダ][カテゴリ] │ 王都の地理   未保存  コピー管理        │ 王都の歴史         │
│取り込み│ ▾ 世界観            │ [編集][プレビュー][左右分割] [Undo][保存]│ 地方制度           │
│ゴミ箱  │   王都の地理  ◀選択  │ ┌─────────────────────────────────────┐ │                    │
│設定    │   王都の歴史         │ │ # 王都の地理                        │ │                    │
│        │ ▸ 人物              │ │ 本文（設定資料のMarkdown）           │ │                    │
│        │ [新しい資料]        │ │                                     │ │                    │
│        │ [幅調整]            │ └─────────────────────────────────────┘ │                    │
├────────┴──────────────────────┴─────────────────────────────────────────┴────────────────────┤
│ 未保存  | コピー管理 | 作品：霧の王都                                                      │
└──────────────────────────────────────────────────────────────────────────────────────────────┘
```

`●`は未保存の補助記号で、必ず「未保存」も併記。左端の機能ナビと資料ツリーは別階層。フォルダとカテゴリは同じ資料を開く。右は関連情報で、次の左右分割の右資料ペインとは別。Tab列が長くなれば横スクロールまたはオーバーフロー一覧を使い、現在タブと閉じる操作を常に到達可能にする。

## SCR-02／03：2資料の左右分割

```text
┌──────────── 左探索 ────────────┬────────────────────────── 中央作業領域 ────────────────────────────┐
│ フォルダ / カテゴリ / タグ       │ [資料タブ群：選択中と未保存を区別]                                    │
│ 資料ツリー                      │ ┌──────────── 左：王都の地理 ─────────┬───────── 右：王都の歴史 ────────┐ │
│                               │ │ [編集][プレビュー] [保存]          │ [編集][プレビュー] [保存]       │ │
│                               │ │ Markdown本文                       │ Markdown本文                    │ │
│                               │ │ 独立スクロール                     │ 独立スクロール                  │ │
│                               │ └───────────────────────────────────┴───────────────────────────────┘ │
└───────────────────────────────┴─────────────────────────────────────────────────────────────────────┘
```

各ペインの資料名・状態・操作を明示する。左側の「編集／プレビュー／左右分割」は**表示方式**、2資料の左右分割は**資料配置**なので混同しない。後者では関連情報を一時的に畳み中央幅を優先する案。幅変更はポインタとキーボード代替操作を提供する。

## SCR-04：検索ビュー

```text
┌──────────── 左探索 ────────────┬─────────────────────────────────────────────────────────────────────┐
│ [検索] 現在位置                 │ 検索 [名前・別名・本文を検索________________]                          │
│                               │ 範囲：(●)作品内全資料 ( )現在の資料                                  │
│                               │ 絞込：[フォルダ] [カテゴリ] [タグ]   並び：[関連度順 v] [条件解除]    │
│                               │ ┌────────── 結果 12件 ──────────┬──────── 選択結果のプレビュー ─────┐ │
│                               │ │ ▶王都の地理　世界観/都市       │ 王都の地理　該当箇所             │ │
│                               │ │  …王都の中央には…             │ 「王都」を強調表示               │ │
│                               │ │  王都の歴史　世界観/歴史       │ [資料を開く]                     │ │
│                               │ └──────────────────────────────┴─────────────────────────────────┘ │
└───────────────────────────────┴─────────────────────────────────────────────────────────────────────┘
```

結果の**選択**でプレビュー、`Enter`または「資料を開く」でタブへ進む案。0件なら結果領域に「一致する資料は0件。範囲と絞り込みを確認してください」＋「条件解除」。検索失敗なら0件とは区別して理由・再試行を表示。戻った時に条件とスクロールを保持する。

## SCR-06：Quick Recall（約420×560pxの仮寸法）

```text
┌────────────────────────────────────────┐
│ Quick Recall   作品：霧の王都   [－][×] │
├────────────────────────────────────────┤
│ 検索 [人物・地名・過去の出来事________] │
│ 結果 3件                              │
│ ▶王都の地理                           │
│  王都の歴史                           │
├────────────────────────────────────────┤
│ 王都の地理　概要                       │
│ 主カテゴリ：世界観   タグ：王都        │
│ 要点：城壁と河港がある都市…           │
│ [詳細を見る] [資料を編集]              │
├────────────────────────────────────────┤
│ [簡易メモを開く]                       │
└────────────────────────────────────────┘
```

結果と概要を縦積みとし、幅の狭い横二列は採用しない。詳細・編集・メモを開いた時は上部の作品名と検索導線を残し、内容領域だけ切り替える。メモは本文と別の「メモ未保存」を示す。最小化／閉じるの本番意味はUX-Q02未決。ブラウザでは前面固定・他アプリへのフォーカス復帰を保証しない。

## 補助画面とモーダルの骨格

| 画面 | 領域順 | 主要な空・失敗状態 |
|---|---|---|
| SCR-01 作品選択 | 新規作品作成→既存作品→短いガイド | 0件は作成へ。名前エラーは入力直下に表示し値を保持 |
| SCR-05 取り込み | 1対象→2 COPY/DIRECT→3配置→4確認→5結果。各段階に「戻る」 | 対象0件は次へ進めない。衝突は対象名・理由とスキップ／名前変更。実ファイル操作なし |
| SCR-08 ゴミ箱／アーカイブ | 状態切替→一覧→詳細→復元／解除 | 0件を状態ごとに表示。復元衝突は元の削除状態を保持 |
| MOD-01 未保存 | 対象資料→影響→保存して進む／破棄して進む／キャンセル | 保存失敗時は閉じずドラフトを保持 |
| MOD-02 同名衝突 | 競合する名前・位置→名前変更／スキップ／キャンセル | 上書き既定なし |
| MOD-03 編集競合 | 双方の変更があること→比較／再読込／キャンセル | 比較・再読込の実処理は未決。暗黙の破棄なし |
| MOD-04 削除 | 対象件数・復元可否→削除／キャンセル | モックは論理状態のみ。DIRECTの実ファイルは触れない |

## 幅・拡大時の変形規則（仮説）

- 1366×768：関連パネルを閉じられる。左探索と中央を残す。縦方向の各領域は独立スクロールし、固定操作に末尾を隠さない。
- 1440×900：3領域を基準に、本文行長を約60〜75字に抑える。
- 1920×1080：本文だけを全幅に伸ばさず、余白・関連情報に配分する。
- 125%／150%相当：上端は必要に応じて操作をメニューへ収め、文字を縮小しない。関連情報を先に畳み、左探索も閉じられる。閉じた領域の再表示ボタンを残す。

同一シナリオで3テーマ・3画面サイズ・2拡大条件を比較する。フォーカス順、長い資料名、検索0件、未保存、保存失敗、競合、削除／復元を必ず含める。これは**検証計画**であり、ブラウザ実測済みではない。
