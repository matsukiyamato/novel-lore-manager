# Storybook Atelier — 視覚仕様

状態：3テーマ比較用の設計提案。構造・文言・操作は `shared-ux.md` と `shared-wireframes.md` に従う。製品仕様の承認ではない。

## 計画→批評→改訂

初案：古書の索引、温かな紙、資料見出しだけ明朝、製本の綴じ目に由来する境界。文書は左揃えで同じ密度の作業面に置く。

```text
共通上端
機能ナビ | 資料探索 | タブ・明朝の資料名 / 無地の編集面 | 関連資料
共通下端              Quick Recall: 検索 / 結果 ║ 概要
                                      必要な境界だけ綴じ目
```

批評：羊皮紙色と明朝を全面に敷くと定型的な古書UIになり、日本語本文とMarkdown記号が読みにくい。明朝は資料・プレビュー・概要の見出しだけ。紙は均一な色で示し、染み・罫線・ページめくりを削除。綴じ目は既存の領域境界の描き方だけとする。

## 基本色：6色

| 名称 | HEX | 用途 |
|---|---|---|
| 表紙裏 `canvas` | `#EFE9DA` | 外周・機能ナビ |
| 無地の本文紙 `surface` | `#FAF6EA` | 編集・プレビュー・概要 |
| 索引紙 `surface-raised` | `#E7DECA` | タブ・入力・選択 |
| 墨 `text` | `#302B25` | 本文・見出し |
| 鉛筆 `text-muted` | `#625B51` | 補助説明 |
| 焦茶 `accent` | `#5B4537` | 選択・リンク・主要操作 |

意味色の補助値：焦点 `#6A4B21`、意味のある境界 `#8A7B65`、失敗・削除警告 `#983C35`。本文面に模様を重ねない。

単色対比の計算値：本文／本文紙12.97:1、補助／本文紙6.20:1、本文／索引紙10.48:1、焦茶／本文紙8.27:1、焦点／本文紙7.36:1、境界／本文紙3.81:1、警告／本文紙6.41:1。SCR-02見出し・入力・選択、SCR-06検索欄・選択結果・概要、DIRECT注意、エラーとモーダルを検証対象とする。境界／索引紙や合成色は実装後に測る。通常文字4.5:1、意味を持つ境界・アイコン・焦点3:1を下限とする。

## 文字・造形

- 日本語UIとプレビュー本文：`Yu Gothic UI`, `Meiryo`, `Noto Sans CJK JP`, sans-serif。操作14px/500、本文16px/400、プレビュー行高1.75。
- 資料名、プレビュー見出し、Quick Recall概要見出し：`Yu Mincho`, `MS PMincho`, `Hiragino Mincho ProN`, serif。画面見出し20px/600、文書見出し24/20/18px。フォールバック時も枠高を共通寸法に保つ。
- Markdownソース：`Cascadia Code`, `Consolas`, `Yu Gothic UI`, `Meiryo`, monospace。16px/1.65。日本語にラテン等幅字体だけを当てない。
- 全テーマ共通の4px刻み：行内8px、操作間8px、領域内16px、見出し下24px。長文約60〜75字、左揃え。両端揃えは使わない。紙らしさのために行高・タブ高・パネル幅を増やさない。
- 通常境界1px、選択は領域内2px線、角丸4px。影はモーダルと独立小窓の外縁だけ。

## 状態と記憶点

| 状態 | 表現 |
|---|---|
| 選択 | 索引紙の面＋焦茶の2px内側線＋文字ウェイト。タブには共通の下線 |
| hover / pressed | 面色と線を一段変える。紙を浮かせない |
| focus | 焦点色の2px外側輪郭。選択と共存 |
| disabled | 操作不可の見た目とセマンティクス。理由は薄茶にしない |
| unsaved / saved / error | 同位置の「未保存」「保存済み」「保存に失敗」。失敗には対象・理由・再試行 |
| archived / trashed | 状態語とアイコン。古い紙色だけで代用しない |

記憶点は**製本の綴じ目**一つ。SCR-02では探索と作業領域、SCR-06では結果と概要の既存境界に内側1pxの陰影を重ねる。幅・位置・DOM・操作を変えない。演出は見出しと領域境界まで。Markdown入力、検索抜粋、COPY/DIRECT説明、エラー、削除確認は無地。Quick Recallの結果本文もゴシックで読む。

同型カード、広告的ヒーロー、根拠のないグラフ、無意味な見出し、全大文字ラベル、染み、蝋印、カール、全面明朝、ページめくりアニメーションは禁止。操作結果以外の動きを置かず、`prefers-reduced-motion`で遷移をなくす。1366×768・1440×900・1920×1080、125%・150%相当、キーボードと失敗・空状態は実装後に検証する。現段階では未実測。
