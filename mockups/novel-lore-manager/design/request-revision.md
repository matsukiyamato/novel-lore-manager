## 設計と比較

参照画像の起動画面は「アプリ名 → 季節の木 → 端末日時 → 作品を選ぶ」の順。作品画面は「見出し → 最近開いた本 → 書棚」の順。既存の作品作成フォーム、本を開く操作、初回ガイドは維持した。画像中の作品検索、ファイル読み込み、更新日時などは機能として追加していない。

視覚計画：Forest は深森 `#14201a`、書棚 `#25352c`、葉 `#8ea87d`、金 `#d4a359`。Storybook は紙 `#faf6ea`、書棚 `#e8dfca`、革 `#7e674f`、罫線 `#8a7b65`。Quiet は白紙 `#fffefa`、霧 `#edf3ee`、常緑 `#315f4a`、罫線 `#82988a`。書名は明朝、操作と資料本文は日本語ゴシック。中央寄せの起動画面と、左揃えの書棚・作業画面を使う。3テーマの DOM、操作、データは共通とし、各テーマの既存色トークンを使用する。

```
起動       [アプリ名]
           [季節の木]
           [端末日時]
           [作品を選ぶ]

作品       [作品名・説明]
           [最近開いた本]
           [すべての作品の書棚]
           [既存の作品作成フォーム]
```

汎用のカード一覧に寄せず、本の背と表紙の形を作品選択の識別要素にした。画像にある架空の日時や作品件数は表示しない。ユーザーの設定資料を管理する製品なので、装飾は作品画面と起動の木に集中させ、検索・保管庫・ルビ入力は高密度で読みやすくした。

## 実装・検証

- 共通 HTML/CSS：起動画面の木を画像比率に近づけ、作品画面を最近開いた本と書棚を中心に再配置。3テーマは既存のテーマ CSS と共通 DOM を使用。
- JavaScript：保管庫の検索窓、状態タブ、タグ絞り込みを順に配置。ルビ辞書の登録と一覧を切り替え、登録結果を通知。Quick Recall にもルビ登録を追加し、最小化・閉じるボタンの重複記号を除去。
- 取り込み結果の不具合：`renderWorkspace()` が専用ビュー表示中にも編集領域を再表示していた。専用ビュー中は資料一覧・編集領域を隠す。
- `node --check`、既存 `tests/smoke.mjs`、`git diff --check` は通過。ブラウザ接続ホストが利用できず、3テーマの画面幅別スクリーンショット・読み上げ・実操作は未検証。
- 本番ファイル、実資料、外部 API、ネットワーク依存には触れていない。
