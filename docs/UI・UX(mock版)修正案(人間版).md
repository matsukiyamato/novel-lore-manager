## Quick Recall画面
   Quick Recall画面1.png参照：
   - 検索結果の内容は継続

   Quick Recall画面2.png参照：
   - 詳細を見るボタンでは.mdファイルの内容をプレビュー画面に変換して見えるようにして欲しい。
   
   Quick Recall画面3.png参照：
   - この資料を編集ボタン継続
   - 簡易メモは合ってOK
   - この資料を編集ボタンの下に、設定検索ボタン、簡易メモ、ルビ検索・表示ボタン、取り込みボタン、保管庫のボタンを追加して欲しい。
   - ↑の内容は設定検索のところと検索結果のところは表示しつつ、そのほかボタン(簡易メモ、ルビ検索・表示ボタン、取り込みボタン、保管庫のボタン)が押された場合、選択した資料の概要をそのほかボタンの画面に切り替えることが出来るようにする。
   - ルビ検索・表示ボタンを押すと、検索窓と、表示形式(小説家になろう、カクヨム、アルファポリスなどの対応したルビを選択するための物が出てくる。)を選択することが出来る。選択すると、小説家になろうの場合は「○○」、カクヨムの場合は「○○」、アルファポリスの場合は、「○○」みたいな感じで選べるようにしたい。
   
   **注意**：ルビ検索・表示ボタンは執筆中に使用したいので、小説家になろう、カクヨム、アルファポリスでのルビ表示に対応させる必要がある。
