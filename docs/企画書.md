1.  企画概要

1.1 企画名

仮称：

Novel Lore Manager

1.2 コンセプト

書くためのアプリではない。 書く手を止めないための設定管理アプリ。

本アプリは、小説本文そのものを執筆するためのエディタではない。

小説制作時に必要となる、

キャラクター

国家

組織

世界観

能力

魔法

武器

アイテム

用語

ルビ

伏線

時系列

地図

人物関係

などの設定情報を、

保存

整理

検索

関連付け

確認

することを目的としたWindows向けデスクトップアプリケーションとする。

ユーザーは、

アプリへ直接設定を書き込む

Markdownファイルを読み込む

TXTファイルを読み込む

といった方法で設定を登録できる。

最終的には、

通常検索

Quick Recall

音声検索

Relation Graph

Local RAG

などを組み合わせ、

「あの設定、何だったっけ？」を数秒で解決する

ことを目指す。

2.  企画背景

長編小説やシリーズ作品では、作品の成長に伴い設定情報が増加する。

例：

キャラクター

人間関係

国家

組織

種族

地域

地理

魔法

能力

武器

アイテム

固有名詞

ルビ

世界史

イベント

伏線

時系列

設定量が増えるにつれて、作家は、

「設定を考えること」

だけではなく、

「以前決めた設定を探すこと」

にも時間を取られる。

特に長期連載では、

どこに設定を書いたか忘れる

設定を作ったこと自体を忘れる

同じ設定が複数ファイルに存在する

古い設定と新しい設定が混在する

人物関係が分からなくなる

ルビを忘れる

時系列を忘れる

伏線を回収したか分からなくなる

といった問題が発生する。

本アプリでは、この

「既に作った情報を再発見する問題」

を中心課題として扱う。

Nolaでは、

一方、本企画ではNolaと同じ方向で競争しない。

Nola：

執筆＋設定管理

Novel Lore Manager：

設定検索・設定参照特化

とする。

などを管理できる。

一方、既存ツールの利用者レビューでは、

キャラクター画面を開くまで時間がかかる

プロット表示に待ち時間が発生する

など、動作速度についての不満も見られる。

高機能性より設定到達速度

を優先する。

を採用する。

6.  問題定義

本企画が解決する中心問題は、

小説執筆者が過去に決めた設定を探すために、本文執筆を中断してしまうこと

である。

特に、

小説家になろう

カクヨム

秀丸

Visual Studio Code

Word

Nola

など別の執筆環境で本文を書いている場合、

設定確認のために、

別アプリを開く

Folderを探す

Character画面を開く

対象項目を探す

必要がある。

この操作が、

執筆の集中を切る原因

となる。

本アプリでは設定検索時間を減らすことで、この問題を解決する。
