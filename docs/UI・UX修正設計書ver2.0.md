   - 設定を書き込む時に、.mdファイルの記号など知らない人が多いと思うので、その時用の書き方の例と書き方が乗った画面が欲しい。

 ・ルビ辞書登録・一覧画面：
  - ルビ辞書の登録画面の作成
  - ルビを付ける単語とルビ自体の名称を紐づけて登録する、使用する場所(小説家になろう、カクヨム、アルファポリス)を選択して保存することが出来る。
  - 入力された単語とルビは紐づけられると、【小説家になろう、カクヨム、アルファポリス】で執筆する際のルビ形態に自動変換されて保存される。その時に、設定した際のルビと、自動変換されたルビのデータは登録されたデータとどちらも紐づけて表示されること。
  **注意**：Quick Recallのルビ検索・表示機能で確認できるようにするための物。

  資料一覧画面：
  - ルビ辞書登録・一覧画面に登録されている物を元に、ルビ辞書画面ルビ検索・表示が出来るようにする。  
  - 【現在の資料】のところの隣にルビ設定で【小説家になろう、カクヨム、アルファポリス】を選択しておくことで、もしもルビ辞書登録・一覧で登録されている時に設定を書いている際に、辞書に登録された単語を書くと、Git hub copilotみたいな感じで単語の次に薄くルビが出てきて、マウスで先のところをクリックしたり、Tabキーを押すことで反映させることが出来る。

  **注意**：薄く出てくるときの例
  (例)：
  【小説家になろう】
  星降る夜(単語のみ)→星降る夜(単語)+薄く(ルビが出てくる。) 

  - 単語を書いた時に、薄く出る物で、仮に同じ単語で複数個あった場合は単語を選択した際に、右クリックで同じ単語名で登録されたルビを複数表示できるようにする。その時に、薄い文字で出るわけじゃなくて、予測変換みたいな感じの表記にしてほしい。

  した：下、舌みたいな感じでPCで日本語を入力すると小さく表示されて、スペースで上から下に行ってEnterを押すとそれを選択できる。
