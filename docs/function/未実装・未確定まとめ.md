## 未確定の判断事項

- **作品カードの情報**：参照画像には著者、作品の進行状態、更新日時、表紙画像があるが、本文で追加必須と列挙された機能は「最近開いた作品」「全作品の本型表示」「新規作品追加」。カード項目のデータ定義・保存方法・どこまで画像に合わせるかは決まっていない。現行は作品名・ジャンル・資料件数を表示する（`js/flows.js` 40行）。
- **作品一覧の並び順**：画像は「最終更新日順」、現行は「最近開いた順／作品名順」（`js/flows.js` 44～45行）。開いた日時と資料を変更した日時を区別し、更新日順を必須とするか判断が必要。
- **タグ検索の方式**：現行保管庫は既存タグの選択式（`js/flows.js` 93～97行）。自由入力による部分一致も求めるかは、追加指定の文章だけでは確定しない。
- **データ管理の承認待ち**：[data-management-design.md](data-management-design.md) DM-Q01～Q08（同一資料ID、同名範囲、COPY／DIRECTの単位、TXT形式、更新操作、Quick Recall共有、DIRECT削除、異常終了時の復旧）は提案・暫定のまま。[user-flows.md](user-flows.md) UX-Q01～Q04、[screen-specifications.md](screen-specifications.md) UX-Q05～Q06もレビュー対象。モック上の動作を承認済み製品仕様とは扱わない。
