小説設定リファレンス・マネージャー

画面一覧 v0.1

作成時点：2026年9月

1.  画面設計方針

本アプリは小説本文を執筆するためのエディタではなく、

設定を登録する

設定を整理する

設定を探す

設定を確認する

設定同士の関係を見る

ことを目的とする。

そのため画面設計では、機能数よりも、

「目的の設定へ最短で到達できること」

を最優先する。

基本UIは、

Shelf

Explorer

Detail

Relation

Popup

の5要素を中心に構成する。

2.  画面レベル定義

画面を以下の3段階に分ける。

MVP

設定検索というプロダクト価値を検証するために必須。

60%版

日常的な設定管理アプリとして利用するために必要。

完成版

高度機能・AI・外部連携を含む。

42. 画面設計における共通ルール

Rule 01

設定を表示するまで3アクション以内を目標とする。

Rule 02

既知設定は5秒以内で確認。

Rule 03

Quick Recallには不要情報を出しすぎない。

Rule 04

AI機能使用時はAI使用中であることを明示。

Rule 05

Auto Save状態をユーザーへ表示。

Rule 06

Deleteには確認を入れる。

Rule 07

Keyboard操作を優先する。

Rule 08

Explorerは現在位置が分かる構造にする。

Rule 09

大量データでも一度に全部描画しない。

Rule 10

執筆画面の邪魔をしない。

本アプリは、

Homeで世界を選び、Mainで整理し、Quick Recallで瞬時に呼び出す
